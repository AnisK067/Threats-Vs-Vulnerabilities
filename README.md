# Threats-Vs-Vulnerabilities
Lab 1: Threats vs Vulnerabilities


| No | Scenario | Category | Explanation |
| :---: | :--- | :---: | :--- |
| **1** | An employee receives an email from "HR Department" asking to verify their login details via a link. | **Threat** | This is a phishing attack where an outsider tries to trick staff into giving away passwords. |
| **2** | A company server is running Windows Server 2012, which no longer receives security updates. | **Vulnerability** | Running end-of-life software leaves known security holes unpatched. |
| **3** | A developer accidentally uploads API keys to a public GitHub repository. | **Vulnerability** | Human error and bad configuration exposed secret access keys publicly. |
| **4** | A hacker uses a botnet to flood a website with traffic until it becomes unavailable. | **Threat** | An active DDoS attack launched by external hackers to crash the service. |
| **5** | The firewall in a branch office is misconfigured to allow all inbound traffic. | **Vulnerability** | A weak network setup that leaves the door wide open for unauthorized traffic. |
| **6** | An insider copies confidential customer data onto a personal USB drive. | **Threat** | An internal authorized user abusing their access to steal sensitive data. |
| **7** | The organization's password policy allows users to set "12345" as their password. | **Vulnerability** | Poor security policy that permits easily guessable credentials. |
| **8** | Cybercriminals send ransomware through email attachments to multiple employees. | **Threat** | Malicious software sent by attackers to compromise devices and demand a ransom. |
| **9** | A company website doesn't validate user input in its contact form, allowing malicious SQL commands. | **Vulnerability** | A coding defect (SQLi) caused by failing to sanitize user inputs. |
| **10** | Attackers use fake job advertisements on social media to trick users into sharing personal data. | **Threat** | A social engineering tactic manipulating users into revealing private details. |

---

## Summary
* **Threat:** Any external or internal force/attack attempting to cause harm.
* **Vulnerability:** A weakness or flaw in code, configuration, or policy that allows a threat to succeed.
